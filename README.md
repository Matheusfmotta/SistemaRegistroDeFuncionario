API desenvolvida para centralizar e gerenciar o fluxo de informações de colaboradores. O sistema permite o cadastro, atualização, remoção e consulta detalhada de funcionários.
Projeto focado em aplicar conhecimento adquiridos de ecossistema Spring, melhores práticas de desenvolvimento backend, arquitetura de software e banco de dados.

🚀 Tecnologias:
Java
Spring Boot (Web, Data JPA, Lombok, Flyway Migrations, MapStruct)
MySQL (Banco de dados)
Maven (Gestão de dependências)

🏗️ Arquitetura
O projeto utiliza a Arquitetura em Camadas para garantir escalabilidade e fácil manutenção:

Controller: Gestão de rotas e requisições HTTP.
Service: Lógica de negócio e validações.
Repository: Comunicação com o banco de dados via JPA.
Entity: Mapeamento objeto-relacional (ORM).
DTO: Transferência de dados segura entre camadas.
